# Pilot playbook

## Before kickoff

- State clearly: **no push notifications in MVP**. Require an open-app cadence; unread badges are the safety net.
- Pick 1–2 agents and ~5 assistants for the pilot.
- Create accounts, workspace rooms, and assignments in the app.
- Agree a hard cutover date with the WhatsApp group.

## Cutover day

1. Post the app URL and cutover time in WhatsApp.
2. Freeze the WhatsApp group to admin-only.
3. Outgoing assistant posts a short context summary as the first message in the agent workspace.
4. All further replies happen in ICC Messaging.

## After two quiet weeks

- Archive the WhatsApp group.
- Roll the next batch of agents the same way.

## Feedback → fix list

Capture:

- Missed messages / unread confusion
- Swap + history preset misunderstandings
- Mobile friction (composer, attachments)
- Anything people still do in WhatsApp

Push notifications are v2 item #1.
